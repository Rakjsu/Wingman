# Screenshots

Drop PNG captures here and link them from the root `README.md`.

Suggested set, all at 1180×780 (the default window size):

| File              | What to capture                                    |
| ----------------- | -------------------------------------------------- |
| `discover.png`    | Discover with the curated categories visible        |
| `installed.png`   | Installed list, a few rows selected                 |
| `updates.png`     | Updates with at least one package pending           |
| `details.png`     | The package details dialog                          |
| `dark.png`        | Any section in the dark theme                       |

Capture with `Win` + `Shift` + `S`, or run `npm run tauri dev` and use the
window's own title bar for a clean frame.
